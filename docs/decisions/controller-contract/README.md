# Controller contract decisions

Changes to a position the PRD takes. One `*.md` per decision, each stating what
the PRD said, what changed, and the evidence that forced it.

These are not preset promotions — those live in `../context-wheel/` and are
gated by `002` WHEEL-T9. These are changes to the input contract itself, and
they are recorded because a contract that moves silently is not a contract.
